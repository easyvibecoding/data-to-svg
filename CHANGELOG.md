# Changelog

## 1.1.0 - 2026-09-03

- Add horizontal bar, scatter, interval, and heatmap rendering selected from a 637-item published chart corpus audit.
- Add explicit currency/value prefixes and independent scatter-axis units.
- Let line charts and heatmaps preserve supplied missing values as gaps or `N/A` instead of zero.
- Expand accessible SVG descriptions to include the supplied plotted data.
- Add corpus-derived examples, validation tests, and chart-selection documentation.

## 1.0.0 - 2026-09-03

- Initial open-source release.
- Add bar, grouped-bar, and line chart rendering from validated JSON.
- Add optional local PNG conversion with `rsvg-convert`.
- Add the installable `data-to-svg` Codex skill, bilingual documentation, tests, and CI validation.
